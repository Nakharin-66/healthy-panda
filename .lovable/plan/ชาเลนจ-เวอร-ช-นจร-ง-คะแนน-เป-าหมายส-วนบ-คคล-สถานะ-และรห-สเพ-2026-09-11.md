# ชาเลนจ์เวอร์ชันจริง: คะแนน เป้าหมายส่วนบุคคล สถานะ และรหัสเพื่อนถาวร

## 1. สิ่งที่มีอยู่แล้ว (ใช้ต่อ ไม่สร้างซ้ำ)

- `challenges` — ชื่อ, คำอธิบาย, ไอคอน, หมวดหมู่, ประเภทการวัดผล, เป้าหมาย, หน่วย, รูปแบบเป้าหมาย (รายวัน/สะสม), ช่วงวันที่, เจ้าของ, รหัสชาเลนจ์ `CH-XXXXX`, สิทธิ์การเข้าร่วม, สิทธิ์การดูอันดับ
- `challenge_participants` — ความคืบหน้า, สถานะสำเร็จ (คำนวณโดยระบบเท่านั้น)
- `challenge_invites` — คำเชิญ (รอตอบรับ/ตอบรับ/ปฏิเสธ/ยกเลิก)
- `profiles.friend_code` — รหัสเพื่อน `HP-XXXXXX` สร้างอัตโนมัติตอนสมัคร ไม่ซ้ำ
- `friend_requests`, `friendships` — คำขอเพื่อน + เพดาน 50 คน
- `activity_logs`, `exercise_logs`, `water_logs`, `daily_statistics` — ข้อมูลจริงที่ใช้คำนวณ
- `daily_goals` (ก้าว/แคลอรี/น้ำ/การนอนต่อวัน) และ `exercise_goals` — ใช้เป็น "เป้าหมายส่วนบุคคล"
- `user_settings.privacy_level` — คุมการมองเห็นในตารางอันดับ

ยังไม่มี: วิธีคิดคะแนน, คะแนนเต็ม, ชาเลนจ์แบบอ้างเป้าหมายของแต่ละคน, สถานะชาเลนจ์, หมวด "การนอน"

## 2. สิ่งที่จะเพิ่มในฐานข้อมูล (ขออนุมัติก่อนรัน)

เพิ่มคอลัมน์ใน `challenges` เท่านั้น ไม่มีตารางใหม่ ไม่ลบคอลัมน์ใด:

1. `scoring_type` — "ทำครบรายวัน" หรือ "ตามสัดส่วนเป้าหมาย"
2. `max_score` — คะแนนเต็มของชาเลนจ์ (ระบบคำนวณให้ตอนสร้าง)
3. `target_source` — ใช้เป้าหมายเดียวกันทุกคน หรือใช้เป้าหมายของแต่ละคน
4. `status` — เปิดรับ / กำลังดำเนินการ / สิ้นสุดแล้ว / ปิดรับสมาชิก / ยกเลิก
5. เพิ่มค่า `sleep` ในหมวดหมู่ชาเลนจ์
6. `challenge_participants.score` — คะแนนที่ระบบคำนวณ (ผู้ใช้แก้ไม่ได้)

ฟังก์ชันฝั่งฐานข้อมูลที่จะปรับ:

- คำนวณเป้าหมายรายคน: ถ้าเป็นชาเลนจ์แบบเป้าหมายส่วนบุคคล จะดึงเป้าหมายรายวันของผู้ใช้เอง (ก้าว/น้ำ/แคลอรี/การนอน) มาใช้แทนเป้าหมายกลาง
- คำนวณคะแนน: รายวัน = ทำครบ 1 วันได้ 100 คะแนน; ตามสัดส่วน = เปอร์เซ็นต์ของเป้าหมาย โดยจำกัดไม่ให้เกินคะแนนเต็ม
- ตารางอันดับเรียงตาม "คะแนน" แล้วจึงความคืบหน้า และคืนเฉพาะชื่อ รูป คะแนน ความคืบหน้า อันดับ
- ล็อกรหัสเพื่อน: ยกเลิกฟังก์ชันเปลี่ยนรหัส และปิดการแก้ `friend_code` ในระดับฐานข้อมูล
- อัปเดตสถานะชาเลนจ์อัตโนมัติตามวันที่ พร้อมให้เจ้าของปิดรับ/ยกเลิกได้

กฎการเข้าถึง: เจ้าของแก้ได้เฉพาะชาเลนจ์ตัวเอง; คะแนน/ความคืบหน้าเขียนได้จากฟังก์ชันระบบเท่านั้น; ข้อมูลสุขภาพละเอียด (น้ำหนัก ส่วนสูง หัวใจ การนอน อาหาร ข้อมูลอุปกรณ์) ไม่ถูกเปิดเผยผ่านชาเลนจ์; อันดับตรวจทั้งสิทธิ์การดูของชาเลนจ์และความเป็นส่วนตัวของแต่ละคน; กันเข้าร่วมซ้ำและรหัสชาเลนจ์ไม่ซ้ำ

Realtime: `challenge_participants`, `challenges`, `challenge_invites`, `friendships` (มีอยู่แล้ว/เพิ่มให้ครบ)

## 3. หน้าจอที่จะปรับ (คงโทนส้ม/ครีม/น้ำตาล และแถบล่างเดิม)

- หน้า "บัญชี": เอาปุ่มเปลี่ยนรหัสเพื่อนออก เหลือ "คัดลอกรหัส" และ "แชร์รหัส" ใต้หัวข้อ "รหัสของคุณ" และแสดงจำนวนเพื่อน X / 50
- ฟอร์มสร้างชาเลนจ์: เพิ่มหมวด "การนอน", เลือกวิธีคิดคะแนน, เลือกว่าใช้เป้าหมายเดียวกันทุกคนหรือเป้าหมายของแต่ละคน, แสดงคะแนนเต็มที่คำนวณให้แบบสด
- หน้า "ชาเลนจ์ & อันดับ": หัวข้อ "เพื่อน X คน" + "จัดการเพื่อน" + "+ สร้างชาเลนจ์", แท็บ "ชาเลนจ์" / "ตารางอันดับ", การ์ดแสดงชื่อ หมวดหมู่ เป้าหมาย ระยะเวลา ความคืบหน้าจริง คะแนน สถานะ และปุ่มดูรายละเอียด
- หน้ารายละเอียดชาเลนจ์: เพิ่มผู้สร้าง คะแนนสูงสุด สถานะ และสองส่วนใหม่ "วิธีคำนวณคะแนน" กับ "ข้อมูลที่ใช้ในการคำนวณ" พร้อมเชิญเพื่อนแบบเลือกหลายคน คัดลอก/แชร์รหัส และเข้าร่วมด้วยตัวเอง
- สถานะว่างเป็นภาษาไทยครบ: ยังไม่มีชาเลนจ์ / ยังไม่มีผู้เข้าร่วม / ยังไม่มีข้อมูลสุขภาพสำหรับคำนวณความคืบหน้า
- รูปโปรไฟล์: ทุกหน้าที่แสดงรูปคน (บัญชี, เพื่อน, โปรไฟล์เพื่อน, อันดับ, รายละเอียดชาเลนจ์, หัวหน้าจอ) ใช้ตัวแสดงรูปเดียวกัน คือรูปที่ผู้ใช้อัปโหลด และกลับเป็นรูปเริ่มต้นของผู้ใช้ที่ดึงมาได้เมื่อผู้ใช้ลบรูป

ไม่มีข้อมูลสมมติในทุกขั้นตอน ระบบเข้าสู่ระบบ เป้าหมาย กิจกรรม และข้อมูลสุขภาพเดิมไม่ถูกแก้

# ระบบเพื่อน + ชาเลนจ์ + ตารางอันดับ (ของจริง ไม่ใช้ข้อมูลสมมติ)

## ตารางที่มีอยู่แล้ว (จะใช้ต่อ ไม่สร้างซ้ำ)
- `profiles` — ชื่อที่แสดง, รูป, streak
- `challenges` — ชื่อ, คำอธิบาย, ไอคอน, ช่วงวันที่, แต้มรางวัล, สถานะเปิด
- `challenge_participants` — ความคืบหน้า, สถานะสำเร็จ
- `water_logs`, `activity_logs`, `exercise_logs`, `daily_statistics` — ใช้คำนวณความคืบหน้า
- `user_settings.privacy_level` (ส่วนตัว/เพื่อน/สาธารณะ) — ใช้เป็นตัวคุมการมองเห็น
- `notifications` — มีอยู่แล้ว ใช้แจ้งคำขอเพื่อน/การยอมรับ

## สิ่งที่ยังไม่มี — ต้องเพิ่ม (ขออนุมัติก่อน)
1. `profiles.friend_code` (ข้อความ, ไม่ซ้ำ) — รูปแบบ `HP-XXXXXX` ไม่ใช้ UUID/อีเมล สร้างอัตโนมัติเมื่อสร้างบัญชี และเติมย้อนหลังให้บัญชีเดิมทุกคน มีฟังก์ชันสุ่มรหัสใหม่แบบกันชนกัน
2. `friend_requests` — ผู้ส่ง, ผู้รับ, สถานะ (pending/accepted/rejected/cancelled) กันคำขอซ้ำและกันส่งให้ตัวเองที่ระดับฐานข้อมูล
3. `friendships` — เก็บสองแถวต่อความเป็นเพื่อน (คู่ไม่ซ้ำ, ห้ามเป็นเพื่อนกับตัวเอง) พร้อมตัวคุมเพดาน 50 คน
4. `challenges` เพิ่มคอลัมน์ประเภทและเป้าหมาย: `metric` (ก้าว/น้ำ/แคลอรี/จำนวนวัน), `target_value`, `unit` — เพื่อเลิกใช้ค่าที่ฝังในโค้ด
5. ฟังก์ชันฐานข้อมูล (ทำงานฝั่งเซิร์ฟเวอร์ ตรวจสิทธิ์เอง):
   - เพิ่มเพื่อนด้วยรหัส / ยอมรับ / ปฏิเสธ / ยกเลิก / ลบเพื่อน (ตรวจเพดาน 50, ซ้ำ, ตัวเอง)
   - ค้นหาโปรไฟล์จากรหัสเพื่อน — คืนเฉพาะรูป+ชื่อ ตามการตั้งค่าความเป็นส่วนตัว
   - คำนวณคะแนนชาเลนจ์จากข้อมูลจริงในฐานข้อมูล (ไม่เชื่อค่าที่ส่งจากหน้าเว็บ)
   - ตารางอันดับ: คืนเฉพาะคนที่ยอมให้แสดง (สาธารณะ, หรือเพื่อน+ตั้งเป็น "เพื่อน")

## กฎการเข้าถึงข้อมูล
- คำขอเพื่อน: เห็น/สร้าง/ตอบได้เฉพาะคำขอที่ตัวเองเกี่ยวข้อง
- รายชื่อเพื่อน: เห็นและลบได้เฉพาะของตัวเอง
- โปรไฟล์: แก้ได้เฉพาะของตัวเอง; คนอื่นเห็นได้แค่รูป ชื่อ และรหัสเพื่อนที่ตรงกัน
- ข้อมูลสุขภาพละเอียด (น้ำหนัก ส่วนสูง การนอน หัวใจ อาหาร ข้อมูลอุปกรณ์) ยังเป็นส่วนตัวทั้งหมด ไม่เปิดให้เพื่อนแม้ตั้งค่าเป็นสาธารณะ
- คะแนน/ความคืบหน้าของคนอื่น อ่านผ่านฟังก์ชันที่กรองความเป็นส่วนตัวแล้วเท่านั้น
- เปิด Realtime ให้ `challenge_participants` และ `friendships` เพื่ออัปเดตอันดับสด

## หน้าจอที่จะทำ (คงโทนส้ม/ครีม/น้ำตาล และแถบล่างเดิม)
- หน้า "บัญชี": เพิ่มบล็อก "รหัสเพื่อนของคุณ" + ปุ่มคัดลอก + ปุ่มเปลี่ยนรหัส (มีคำเตือนและยืนยัน)
- หน้าใหม่ "เพื่อนของฉัน": นับ X/50 สด, ค้นหาด้วยรหัสเพื่อน, ส่งคำขอ, กล่องคำขอที่ได้รับ/ที่ส่ง, ลบเพื่อน, สถานะว่าง/กำลังโหลด/ผิดพลาดเป็นภาษาไทย
- หน้าใหม่ "โปรไฟล์เพื่อน": แสดงเฉพาะสิ่งที่เจ้าของอนุญาต ถ้าปิดจะขึ้น "ผู้ใช้นี้จำกัดการแสดงข้อมูลส่วนตัว" พร้อมเมนู … (ดูโปรไฟล์ / ซ่อนข้อมูล / ลบเพื่อน)
- หน้า "อันดับ": ลบชื่อสมมติทั้งหมด, การ์ดชาเลนจ์แสดงเป้าหมายและความคืบหน้าจริง, ตารางอันดับเรียงตามคะแนนจริง, ตัวกรอง "ทุกคน / เพื่อน", ไฮไลต์ตัวเอง, อัปเดตสดโดยไม่รีเฟรช
- ป้ายจำนวนคำขอใหม่บนแถบล่าง (ใช้ระบบแจ้งเตือนเดิม)

## หมายเหตุ
- ระบบเข้าสู่ระบบเดิมไม่ถูกแก้
- ไม่มีการใส่ข้อมูลตัวอย่างใด ๆ ชาเลนจ์ที่ยังไม่มีค่าเป้าหมายจะถูกกำหนดประเภทให้ตรงกับที่ตั้งชื่อไว้เท่านั้น
